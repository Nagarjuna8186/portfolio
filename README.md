NAGARJUNA YAMALA PORTFOLIO
===========================

Files:
- index.html
- style.css
- script.js
- assets/resume.pdf  <-- copy your resume PDF here

How to use:
1. Extract this folder.
2. Put your resume PDF at assets/resume.pdf.
3. Open index.html in a browser.
4. Replace YOUR_GITHUB_URL and YOUR_LINKEDIN_URL in index.html.
5. Replace YOUR_PROJECT_GITHUB_URL and YOUR_PROJECT_DEMO_URL with actual project links, or remove those links if unavailable.

Technology:
HTML5 + CSS3 + Vanilla JavaScript only.

Notes:
- No React, Tailwind, Bootstrap, Vue, Angular or TypeScript.
- The contact form uses mailto and does not require a backend.
- Blog entries are intentionally marked "Coming soon" until real articles are available.
- The design is an original dark technical/instrument-panel portfolio inspired by the supplied visual reference; it does not copy third-party branding or assets.
